# 코레일 예매 매크로 (개인용 Android 앱)

빈 좌석(취소표)이 뜨면 자동으로 예약까지 처리하고, 텔레그램으로 알림을 보내는 개인용 안드로이드 앱입니다.
**결제는 자동으로 하지 않습니다** — 예약만 자동으로 하고, 알림을 받으면 결제 마감 시간 안에 코레일 앱/사이트에서 직접 결제해야 합니다.

## 설치 방법

1. `app-debug.apk` 파일을 안드로이드 폰으로 옮깁니다 (카카오톡 나한테 보내기, 이메일 첨부, USB 등 편한 방법).
2. 폰에서 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 설치 허용 문구가 뜨면 허용해줘야 설치됩니다.
   - Play 스토어에 등록된 앱이 아니라서 뜨는 정상적인 경고입니다.
3. 앱을 실행하면 알림 권한을 물어봅니다 — 반드시 허용하세요 (결과 알림을 받으려면 필요합니다).

## 새 버전으로 업데이트 (삭제 없이, 설정 유지)

이제 이 프로젝트는 **고정된 서명 키**(`signing/korail-macro.jks`)로 debug/release 모두를
서명합니다. 어느 PC에서 빌드하든 서명이 같으므로, 새 APK를 **앱 삭제 없이 그 위에 덮어
설치**하면 안드로이드가 "업데이트"로 처리하고 저장값(코레일 로그인 ID/비밀번호, 텔레그램
토큰/Chat ID, 최근 역·조건)이 그대로 유지됩니다.

- 폰에서 새 APK를 눌러 → "기존 앱을 업데이트하시겠습니까?" → 확인
- 또는 PC에서: `adb install -r releases/korailmacro-debug.apk`
- 화면 상단 제목 옆의 `v1.1` 표시로 설치된 버전을 확인할 수 있습니다.
- 릴리즈마다 `app/build.gradle.kts`의 `versionCode`를 +1 하세요 (안 올리면 업데이트 거부됨).

> **딱 한 번만 예외:** 이 버전(v1.1)은 서명 키가 이전에 나눠주던 APK와 달라졌습니다.
> 그래서 v1.1로 올라올 때 한 번은 **기존 앱 삭제 후 새로 설치**해야 하고, 이때 로그인 정보를
> 다시 입력해야 합니다. v1.1부터는 계속 덮어쓰기 업데이트가 됩니다.

> 앱을 **완전히 삭제(Uninstall)** 하면 암호화 저장소도 같이 지워져 로그인 정보가 사라집니다.

## 최초 설정

앱 실행 후 아래 항목을 입력합니다:

- **코레일 로그인**: 레츠코레일 계정의 이메일/회원번호/휴대전화 + 비밀번호
- **출발역 / 도착역**: 한글 역 이름 그대로 (예: 서울, 부산). 강릉선(서원주·만종·횡성·둔내·평창·진부) 포함.
- **날짜 · 시작시각**: "날짜 · 시작시각 선택"에서 달력 + **시 + 분(5분 단위)** 까지 지정합니다. 지난 날짜/시각을 고르면 이유를 표시하고 시작을 막습니다.
- **종료시각(선택)**: 시/분 지정 또는 "선택 안함". 이 시간대 안의 열차만 대상으로 하며, 비워두면 시작시각 이후 전체를 봅니다.
- **성인 인원수**, **일반실/특실**
- **재시도 간격(초)**: 1/5/10/15/30/60초. 1초 등 너무 짧게 하면 서버에 부담을 주고 계정이 일시 차단될 수 있으니 급할 때만 쓰고, 평소엔 5초 이상 권장합니다.
- **텔레그램 봇 토큰 / Chat ID**: 아래 방법으로 발급받으세요.

### 텔레그램 봇 만들기

1. 텔레그램 앱에서 `@BotFather` 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름/username 설정 → 완료되면 **봇 토큰**(예: `123456:ABC-...`)을 알려줍니다.
3. 만든 봇과 대화를 한 번 시작(아무 메시지나 전송)합니다.
4. 브라우저로 `https://api.telegram.org/bot<토큰>/getUpdates` 접속 → `"chat":{"id":...}` 값이 **Chat ID**입니다.

### 배터리 최적화 제외 (중요)

화면이 꺼져 있을 때도 안정적으로 계속 시도하려면 "배터리 최적화 제외 설정" 버튼을 눌러 이 앱을 배터리 최적화 대상에서 빼주세요. 안 해두면 안드로이드가 앱을 강제로 잠재워서 재시도가 멈출 수 있습니다.

## 동작 방식

- "시작"을 누르면 포그라운드 서비스(상단 상시 알림)로 실행되어, 설정한 조건으로 코레일 열차를 주기적으로 조회합니다.
- 지정한 좌석 등급(일반실/특실)에 빈 좌석이 뜨는 즉시 예약을 시도합니다.
- 예약에 성공하면: 텔레그램 메시지 발송 + 폰 알림 + 서비스 자동 종료.
- 다른 사람이 먼저 채간 경우엔 실패 로그만 남기고 계속 재시도합니다.
- "중지" 버튼으로 언제든 멈출 수 있습니다.

## 참고 / 주의사항

- 코레일 모바일 앱 API는 **비공식(리버스 엔지니어링)** 방식입니다. 코레일 쪽에서 API를 변경하면 예고 없이 동작하지 않을 수 있습니다.
- 로그인/예약이 안 되면 앱 화면의 "실행 로그"에 서버가 보낸 원문 메시지가 나오니, 그 내용을 알려주시면 원인을 진단해서 고칠 수 있습니다.
- 아이디/비밀번호, 텔레그램 토큰은 폰 안에 암호화된 저장소(EncryptedSharedPreferences)에만 저장되고 외부로 전송되지 않습니다 (코레일 서버, 텔레그램 서버로 가는 정상적인 통신 제외).
- 재시도 간격을 너무 짧게 잡으면 코레일 서버 쪽에서 비정상 접근으로 계정을 제한할 수 있으니 주의하세요.

## 소스 코드 재빌드

```bash
cd KorailMacro
./gradlew.bat assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew.bat assembleRelease   # app/build/outputs/apk/release/app-release.apk (R8 최적화 + 축소)
```

두 빌드 모두 `signing/korail-macro.jks`(개인용 고정 서명 키, 저장소에 포함)로 서명되므로
어느 PC에서 빌드해도 기존 설치본 위에 덮어쓰기 업데이트가 됩니다. 배포용으로는
`releases/korailmacro-debug.apk` / `releases/korailmacro-release.apk` 를 최신으로 갱신해두세요.
